# Privacy policy — Hermes

Last updated: 2026-09-24

**Who uses this application:** only me, its author. There are no other users
and no way to become one.

**What it accesses:** my own Gmail account, with read-only permission
(`gmail.readonly`). It can search and read messages. It cannot send, reply,
forward, delete, archive, label, or mark anything as read — the permission it
holds has no such capability.

**What it does with the data:** messages are read on demand and summarised
back to me. Nothing is copied to any third party, sold, or used for advertising
or model training. No Gmail content is stored outside my own equipment.

**Sharing:** none. No data is shared with anyone.

**Revoking access:** I can revoke it at any time at
https://myaccount.google.com/permissions, which immediately invalidates the
credential.

**Contact:** davidvanhuffel@gmail.com
